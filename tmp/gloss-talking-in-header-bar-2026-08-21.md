Cursor · Talking in / Working on locked in code + Header Bar (2026-08-21)

Gloss-only — not a build lock unless the Document already holds this.

Talking in / Working on is now in the platform, not only in conversation.

Talking in = the Dialog or Session you are in. Working on = Chronicle focus and the Point write target. They can differ. Selecting a Draft no longer abandons the Dialog. Chronicle prefers the Draft when both IDs are set. Point writes follow the focused Draft; the Dialog manuscript is the default only when nothing else is focused. A Draft born in a Session writes to that Draft. Chatter never invents a Document.

The strip above Dialog is the Header Bar (not WorkspaceHeader — that name belongs to Commons/Agent panels). It now names Talking in and Working on in larger type, keeps the domain, and drops the repeated title and the SOLE badge. SOLE is memory status, not orientation. Session id sits behind the chevron. Agents / cueing stay on the cast strip below — that is “and more,” not the title.

This is the linear UI answering: what am I talking in, what am I working on, where will this action land.
