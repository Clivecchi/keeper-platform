Cursor · Agents as story-UI contributors (2026-08-29)

Gloss-only / not a build lock.

Chuck named the remaining gap: we have been improving UI so agents do not have to return a thesis. Drafts and Documents are beginning to do that. Agents still ask permission to propose a Point. That is the exact purpose of UI response — include the Point, let Accept be the consent. No extra turn.

**What is already true**
Point, Document reorganize, and Treatment already work as propose → card / overlay → human Accepts or Applies. The prompt already says do not ask. Keeper even follows up when the model asks “want me to add that as a Point?” and tries to emit the card.

**Why they still ask**
The model still treats the Dialog bubble as the work. Asking is default politeness. The follow-up only catches a narrow phrase. A keeper-card is a display receipt, not a story object. There is no Choice object, so questions stay in prose. Chronicle only moves when an action fires. If the agent talks about a Point instead of placing one, the story stays still.

**The miss**
Drafts and Documents are becoming story-builder. Agent execution is still chat-with-optional-tools. Dialog is voice. Chronicle is the manuscript. The AI’s offer should be the object, not a doctrine essay about the object.

**Options (not locked)**
1. More prompt doctrine and a wider “asked instead of proposing” detector. Cheap. We have already spent this coin.
2. Invert the turn: an operational offer without a Keeper object is incomplete. Keeper completes the object. Relational talk stays prose.
3. Choice as a first-class Keeper object — multiple options, human picks — same family as Point. Do not build this as a one-off card while Points still leak to permission-ask.
4. Story-builder contract: a Keeper turn places objects. Dialog voices them (short). Chronicle holds them. Asking permission in prose is an incomplete turn.

**Recommendation**
Take 4 as the contract. Use 2 as the near execution (treat offer-in-prose as incomplete, not as conversation). Hold 3 as the next object so questions leave the bubble. Do not add another page of instructions and call it UI-first.
