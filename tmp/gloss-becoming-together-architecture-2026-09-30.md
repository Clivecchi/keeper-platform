Cursor · Becoming Together, smallest build (2026-09-30)

Gloss-only until Chuck says Build Becoming Together. Not a universal Trace system. Not Jev. Room Digest stays withdrawn.

Human speaks → Trace → scoped Trail → cheap Cast offers → Lead directs → selected Agent contributes → new Trace → updated Trail → Lead continues or Presents.

Silence is free. Trace is factual. Trail is contextual. Full model participation is selective.

Progressive Cast Room is Trace’s first implementation. Events live as metadata.trace on the Lead message that already stores castVoices and action receipts. Each event is who, what, where, when, and refs. What is spoke, offered, directed, contributed, acted, resolved, presented. No meaning, no relevance score, no plot. Sure silence writes nothing and spends no model call.

The scoped Trail is a projection, built when a prompt is made, from this turn’s events plus the previous turn’s contributed, acted, and resolved facts. It is not stored. It is not Chronicle’s focus breadcrumb. Chronicle Trail stays the right-panel crumb. Agents do not read it.

Offers run only for cued voices when more than one is still unnamed. The call is gpt-4o-mini through a tiny prompt, not the full agent stack. An empty offer is silence. The Lead’s envelope may name one slug and an aim. That field has to be parsed on purpose; unknown envelope siblings are dropped today. One contribution uses the existing full run and sees the updated Trail. The Lead may direct once more. Two contributions, then Present. At Present, the spoken reply, castVoices, receipts, trace, and a consumption row (offering, tokens, latency, cost empty) land on that same message.

Independent consultation stays the explicit parallel path. Empty chips stay Lead only, and those turns still record spoke and resolved.

Consequence stays a Point, a resolved meaning, or a Present. Trace may point at them. The human and the Lead decide them.
