Cursor · Stage attention grammar (2026-09-20)

Gloss-only. Not a build lock beyond the Compose-on-Stage slice already asked.

Stage attention is a grammar, not a chat overlay.

Present → Engage → Yield → Perform → Resolve → Return

Dialog is the first occupant (`attentionSubject: "dialog"`). The states belong to the Stage Frame. Theatre writes `STAGE_YIELD_MOTION` onto the current `slide` Presence instance for every state except Present. Return restores the held Frame after Resolve. Blur is not Return. Scene is still experiential — no table, no collector.

This is the same seam as Compose-on-Stage yield. Other subjects can occupy the same states later without a second Stage architecture.
