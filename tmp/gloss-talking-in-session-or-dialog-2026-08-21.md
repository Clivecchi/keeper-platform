Cursor · Talking in can be a Session (2026-08-21)

Gloss-only / not a build lock.

Talking in / Working on stays. Two specific cases:

Linked Draft + named Dialog — Talking in: that Dialog. Working on: that Draft. The link is the relationship. Do not write the Dialog manuscript just because the session still belongs to the Dialog.

Draft born in a Session — Talking in: that Session. Working on: that Draft. Chatter is not promoted to a Document. Specificity still holds.

Default when nothing else is focused: Talking in and Working on are the same named Dialog Document. Never invent a Document to give a Session a write target.
