Cursor · Same Document, different furniture (2026-08-22)

Gloss-only — not a build lock unless Chuck holds it.

Chuck asked why Becoming Together and Finding the Plot render differently on Chronicle. They should not. They are both Documents.

They already share one shell: DomainRealmStory → DocumentShell. The difference is fill, not type.

Becoming Together was the first Document that received a seed: Forward, Step, and four named Paths (Progress, Known Issues, Development, Cast). Those Paths paint themselves — green, amber, blue, gold — because the shell colors a Path by its title. Finding the Plot received a manuscript so Points have a box. It never received Forward, Step, or Path declarations. So Chronicle shows the same house with the furniture in one room and an empty floor in the other.

Code still calls the colored beds “Paths.” Linked Drafts show as a quieter “Sections” list at the bottom. Chuck’s language is Sections. Those two words are currently two different UIs. That split makes the Documents feel like different products.

Recommendation: every named Dialog Document uses the same chrome. Forward is a Document slot, not a Becoming Together exclusive. A quieter Section is always there for Points that do not yet fit. Authored Sections appear when they exist. Do not copy Becoming Together’s four colored Paths onto Finding the Plot — that is that Dialog’s content, not the Document type.
