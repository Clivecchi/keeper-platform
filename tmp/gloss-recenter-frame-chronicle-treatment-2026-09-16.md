Code truth (what the words already mean)

Chronicle is a Surface: the right panel (`UniversalViewPanel`). It is not a Frame route, not a Prisma Chronicle table, and not Stage. It already hosts more than one body: Document, entity Focus/Config, Act overlays, Reach, Theme, and a Dialog-scoped History tab (`ChronicleEvent`). History is not “Chronicle as time.” It is a mode on the Document shell.

Frame is already five things, and none of them is the first-class experience unit in the handoff:
1. `V0FrameKey` — URL surface (`?frame=cover|present|…`). Member work uses `?board=*`, not these.
2. `Domain.frame_json` slice — cover, commons, kip, etc.
3. Worlds narrative `Frame` — Present pattern object.
4. `KeeperDialogFrame` — Dialog chrome (Header · Dialog · Composer).
5. StageExpression “one Frame” — one `text_slide` beat after Lead meaning.

Stage is a room on the current Board (`workspaceSurface`) plus a named composition (`Domain.settings.keeperStage`). Not `?board=stage`. Not a Prisma Stage. Filmstrip slides still store copied title/body; Moment source is the first live resolve (code wired; UI proof blocked).

Treatment today is a visual configuration object: `name`, palette (paper/accent/ink/signal/action), font. Stored on `frame_json.treatment`. Rendr proposes it; human Applies. README already lists spatial / motion / density as not built. It is not yet an “agreement about expression.” Four theme stores exist and must not be collapsed: frame Treatment, frame theme, Stage theme, Prisma `themes`.

Presence is split: `KeeperPresence` = Chronicle renderer; `StagePresence` = placement reference (kind + objectId + stored title). Stage comments already say assets are references, not clones. Filmstrip performance still mostly copies.

Composer is the Turn instrument (`AgentComposer`). Reach already brings real object ids onto Stage. Look/Reach render in Chronicle, not in Composer.

Lead vs Rendr already matches the performance half of the handoff, not the Frame half:
- Lead: meaning (`resolvedMeaning`), Document writes, full filmstrip via `stage.story.layout`.
- Rendr: Treatment propose on Design; after Lead persist, one Stage beat (`stage_expression`). “You do not decide what the performance meant.”
- Lead is not told “direct the Frame.” Rendr is not told “frame experience” except as one slide. Two writers can hit the same story: Lead replace vs Rendr append.

That capability is closer to Chronicle overlays + Stage composition + Presence routing.
- Treatment-as-agreement is larger than Treatment-as-palette. Do not retrofit the new meaning onto the JSON object.
- Composer-as-composition-instrument is larger than Composer-as-Turn-box.
- Stage is not a Frame. Present is not Stage. History is not Chronicle-as-time.
