Cursor · Stage Chat, object focus, and Composer in Chronicle (2026-08-30)

Gloss-only. Not a build lock. Chuck tested the Stage release and named the misalignment.

What Cursor built
Stage is a room, but conversation still needs a Dialog ticket. Selecting a presence retargets Working on. Agency (Role / Direction) sits on the Stage as a second instrument. Composer appears in two doorways — both currently Reach. The Turn floor is still Dialog’s Composer, parked under the canvas.

What Chuck described
An editor’s table. The Stage holds the story assets. Most talk is about the cohesive story across everything on Stage. Sometimes talk is about one object. Select an object → Chronicle shows it, and conversation may narrow. Do not make the human pick a Dialog to begin. If a Dialog is already on Stage, bind to it. Composer is not Agency and not Reach. Composer is closer to an icon that tells Chronicle to render what is currently exposed, with a toolbar for config.

Recommended contract (proposal, not locked)

1. Stage Chat is the default conversation. Agents consider the whole Stage. No Dialog-card click required to speak.
2. Auto-bind: if a Dialog is on Stage, that Dialog is Talking in. Finding the Plot on Stage is enough.
3. Object select opens Chronicle on that object. It does not steal Stage Chat unless the human is focusing that object.
4. Composer is one place: Chronicle compose mode. Click Composer → Chronicle renders the current exposure (Agency, Role, Direction, Reach, config). Toolbar at the top of that Chronicle surface.
5. Reach is a Composer-toolbar action. Remove Composer / Reach as a peer of Stage in the top bar.
6. Agency is Chronicle Config, not a second Composer on the Stage.
7. Document first contract: Stage Chat writes into the auto-bound Dialog Document. Later we can name Stage Direction vs story presentation as sections. Do not invent a second manuscript yet.

Not the next build unless Chuck locks this. Stage Slice 2 (cue cards) can wait one beat if this contract is the missing spine.
