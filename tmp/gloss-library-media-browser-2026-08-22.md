Cursor · Library as a media browser (2026-08-22)

Gloss-only / not a build lock unless Chuck already locked this on the Document.

Library was a list of names. That will not hold. Library is the place you go to find any and all content — uploads, links, GitHub canon, draft pointers, archive. A vertical list of filenames becomes tedious at ten items and unusable at a hundred.

The redesign treats Library as a media selector in Keeper style: poster cards, thumbnails for images, kind marks for everything else, search, and shelves.

Shelves are not a new hierarchy. Kind is inferred from the source (Images, Videos, Documents, Links, Writing, GitHub). Category tags already on LibraryItem become named shelves when they exist. Archive is its own shelf and stays off the live ones. All still reads as horizontal rails. A chip or a search turns the same items into a grid.

Nav still only opens Library. Dialog still sits underneath. Chronicle still holds the selected item. That pathway did not change.

What this is not: Netflix chrome, hover animation, generated video previews, or a fourth Chronicle layout. Those would fight the board.

Next pressure, when it comes: richer document posters (first page of a PDF, manuscript excerpt), and letting the cast assign category tags from Manage so the shelves grow from use instead of from a pre-built taxonomy.
