What Composer is
The instrument already on the Dialog floor: “Share your thoughts…”, attach, send, Agents cue (Kip · Cloud · Rendr). In code that is AgentComposer.

Title and Cast — Talking in / Working on, “Finding the Plot”, Cast pills, Invite / Get key / Manage — is the conversation chrome Composer works with. It is not a second Composer.

What currently opens is not Composer
The sheet titled COMPOSER / “Bring who or what you need” (search, Cast list, Recent) is Reach: one feature available through Composer. Product language should stop calling that sheet Composer. In code it may stay a small separate module (KeeperComposerSheet) if that stays cleaner.

Implication for Stage
Elevating Composer means elevating this instrument above the Stage — not replacing it with the reach sheet. Reach opens from Composer. Code can stay minimally separate. The UI name Composer belongs to the instrument.

Earlier Slice 3 language that treated the reach sheet as “the new Composer” is withdrawn.
