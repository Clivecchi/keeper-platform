Gloss-only. Not a build lock. Does not create Points or mutate the Document.

Chuck asked for a Re-Center proof: Composer lives above surfaces; Stage is spatial composition; Agency is who someone is plus who they are here; Talking in and Working on stay distinct.

Code reality first. Composer already means the Dialog input floor (`AgentComposer`). Product Stage does not exist — Theatre.js is Present motion, not a rehearsal canvas. Agent identity lives on `kip_agents`. Persistent Cast follows the Dialog (`DialogCastMember`). Board Cast is a code default. Talking in / Working on is already a formal contract.

The slice does not invent a new Agent framework or a fourth column.

What shipped:

- Product Composer is reach. Code name: `KeeperComposerSheet`. The chat floor stays `AgentComposer`.
- First Stage is **Keeper**. It is a workspace surface on the existing board (`workspaceSurface: dialog | stage`), not a new Board and not a Dialog role.
- Stage stores references (`kind` + `objectId`) plus position and contextual Agency on `Domain.settings.keeperStage`. The Document stays the Document. Kip stays Kip.
- Theatre.js is not the source of truth. Present sheets stay Chronicle motion. Stage positions are Keeper JSON.
- Selecting a Stage object sets Working on and keeps Talking in, except a Dialog — that object is the conversation.
- Contextual role/direction is Stage-owned and injected into the Turn. Base Agency is still the agent record.
- Board Cast is unchanged. Composer Cast is the domain roster. Persistent Keeper Cast is the next movement, not this one.

First composition is not a forced Journey. Bring Kip. Bring Finding the Plot if it exists. That is the truthful start.

Deliberately not built: Agency Trace, Theatre choreography, Cast migration off boards, graph connectors, a universal object browser, prompt overhaul.

The one-hand test is the standard. Composer is a bottom sheet. Stage on mobile is a stack. If that still feels like navigating a tree, the next cut is search and Here — not more taxonomy.
