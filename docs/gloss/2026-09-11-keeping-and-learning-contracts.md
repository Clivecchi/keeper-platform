Cursor · Keeping Judgment and Learning Judgment contracts (2026-09-11)

Gloss-only / not a build lock. Design only. Does not create Points.

Two companion Agency contracts. Both begin Experience → Understand. Then they diverge. Four legitimate outcomes: Keeper Form only; Agent learning only; both; neither.

SOLE is not a Form. Keeping is not required in order to learn. Learning is not a substitute for canonical truth.

Keeping Judgment asks: What, if anything, deserves keeping? What Form should it take? Where does it belong?

Form is meaningful structure — kept, understood, related, evolved, experienced. Kind is a reusable pattern of Form. Existing primitives may participate. No Form table. No Dynamic Kinds.

Sequence after Understand: meanings (0..n) → Form Fitness → belonging → supported relationships → genuine focus as presumption → confidence → consequence (Act / Propose / Advise / Notice / Leave As-Is) → capability last.

“No adequate current Form” is competent. A Moment does not require a Journey. Focus creates presumption, not certainty. Agree → quiet. Conflict → collaborative.

Learning Judgment asks, in parallel: What, if anything, should I learn from this experience that will help me become better at being the Agent I am?

The thing learned from ≠ the learning produced. Different Agents may learn differently from the same experience. Learning must stay inside base identity, capability, and authority. Human correction shapes future learning. Often the answer is nothing.

Current limitation (do not design as if solved): SoleReflection.agentId is written; retrieval is Keeper/Domain-scoped and not Agent-specific. Voice/Echo/Logbook are unwired. sole.save today stores recall text, not judged learning.

Reuse: Document composition; Point graph and Reorganize; Point → Moment identity-preserving Keep; Stage presence; Talking in vs Working on; Keeping Choices; SoleReflection.agentId; human SOLE edit/delete; garden names only as future semantics.

Do not build: Form engine, Dynamic Kinds, SOLE rewrite, Focus Truth repair, keyword classifiers, sole.save as Form, shared-cast identical learning.

Smallest later seam (recommendation only): on a Keeping Choice exercise turn, require both judgments before capability. Name Form or “none.” Name learning or “none.” If Form and learning would write the same artifact, that is a contract failure.
