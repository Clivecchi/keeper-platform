Gloss-only / not a build lock. Investigation only. Does not create Points.

Two corrections before any Form Fitness contract.

1. Form is not a storage/object-type choice. Form is the meaningful structure Keeper gives something so it can be kept, understood, related, evolved, and experienced. Kind is a reusable pattern of Form. Point / Document / Moment / Journey / Stage participate in Form; they are not Form judgment.

Code already composes structure without a Form table: Dialog Document (Forward, Sections, Points, Drafts→Kept→Presented); Point graph (status, pathGroupId, references, reorganize Current vs Proposed); Keep that lifts a Point into a Moment while keeping the same id; Stage presences + story slides as presentation of the same objects; Library pointers; EntityKind cover/blocks/presenceSchema as how something is experienced; free draft.kind (manuscript, journey_spec); agent capabilities as who may shape what.

“Keeper helps human meaning take Form” is already partly true. What is missing is naming that composition as Form, and judging Form separately from which primitive currently holds a piece of it.

2. SOLE is Self Organized Learning Environment — Agent-determined learning, with human visibility. Not leftover storage.

Code today: sole.save writes SoleReflection + SoleMemoryCard in one step. Scope is Keeper or Domain, not Agent. agentId is provenance on the Reflection only; retrieval never filters by Agent. Voice / Echo / Logbook are schema + REST, no agent write. Prompts say “durable facts / preferences / how to behave / recall next session.” sole.save is golden-path on every Lead turn.

Live Casting exercise: Kip saved the source principle verbatim, topic “Casting Principle,” linked to Pool Keeper. That was a learning instinct carrying the wrong artifact. Canonical Form of the principle ≠ Kip’s learning from it (“when I am cast, role does not redefine my Agency”).

What this changes: Form Fitness is not “pick Point vs SOLE vs Moment.” Form Fitness asks what structure the meaning needs. Learning Judgment is a parallel question for SOLE. They must not be alternative buckets.
